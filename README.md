# Real-Time Collaborative Whiteboard

This looks like a mini version of:

- Miro
- Figma

## Stack

### Frontend

- React
- TypeScript
- Zustand
- Socket.IO Client
- perfect-freehand
- Vite

### Backend

- Node.js
- Express
- Socket.IO
- TypeScript

## Features Included

✅ Real-time collaboration
✅ Rooms
✅ Real-time undo/redo sync support
✅ Multiplayer cursors
✅ Pencil tool
✅ Rectangle tool
✅ Circle tool
✅ Line tool
✅ Excalidraw-style smoothing
✅ Live shape preview
✅ Clear Board synchronization
✅ Zustand state architecture
✅ Socket sync architecture
✅ Modular canvas renderer

## How to Test

- Open the whiteboard application.
- Draw something on the canvas using the pen tool.
- Open the same URL:
  - in a new browser tab
  - in another browser
  - or on different devices connected to the internet
- Start drawing from any device or tab.
- Watch all changes appear instantly across every connected screen in real time.

## Tips

- While working on local for Web Sockets app project Backend PORTs should be Public.
